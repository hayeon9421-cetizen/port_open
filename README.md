# git 관련
* git은 사이트에서 검색해서 최초설치해야 사용할수있음(git 사용시 설치는 필수)
* git은 설치시 로컬에 히스토리 저장소를 생성한다는 개념 
* github는 원격 git 저장소(원격 git저장소를 사용하려고 해도 반드시 로컬에 git은 설치되어야함)

# git 명령 
* 커밋(commit) - 내 로컬 git 저장소에 저장

# github 프로젝트 공유법

* 저장소 > Setting >  왼쪽메뉴 Collaborators > Manage access 에서 [Add People] 버튼으로 github 가입자 조회 후 초대
* 초대 이메일 발송됨, github에서 초대 알람 간다고함(난 못찾아 메일로 승인)
* 초대 승인후 github 로그인후 완쪽 상단의 메뉴 클릭하면 하단에 레파지토리가 추가되어 있음
